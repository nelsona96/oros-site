# Oros Productions

A photography and videography portfolio and promotional site — weddings, commercial
work, portraiture, and ministry film. Next.js (App Router) + TypeScript + Tailwind, with
Sanity as the content store, Mux for portfolio video, and a palette built entirely from
Radix Colors.

- [`docs/DESIGN.md`](docs/DESIGN.md) — creative direction: mood, color system, typography, motion
- [`docs/SPEC.md`](docs/SPEC.md) — technical scope: stack, content model, routes
- [`docs/BUILD_PLAN.md`](docs/BUILD_PLAN.md) — phased, stacked-PR build sequence
